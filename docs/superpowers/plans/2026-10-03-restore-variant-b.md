# Restore Variant B Implementation Plan

**Goal:** 按用户明确指定的 `design-variant-B.html` 恢复首页视觉，并列出现有版本后续需要用户设计的页面和元素。

**Architecture:** 在现有单人记课工程中仅修改首页、课程卡片的模板/样式和首页导航颜色；不回退数据逻辑，不改云环境、AppID、其他页面布局。沿用现有原生底部导航的三个入口，底部图标列入设计交付清单。

**Tech Stack:** 微信原生 WXML / WXSS、Node.js 内置测试、微信开发者工具。

## 验收范围

- 视觉基准：蓝紫渐变页头、蓝青游泳卡片、橙红钢琴卡片、半透明类型图标、白色全宽打卡按钮、绿色已记录状态、虚线添加课程入口。
- 保留真实累计/总课时/余额、课时超额提示、同步失败与待同步提示、防重复与按钮禁用逻辑。
- 不恢复静态稿的假连续天数、成就入口、桌面悬浮人物；其他类型使用统一渐变兜底，不为每门课程制作素材。
- 统计、我的、详情、添加/编辑页面不擅自重新设计，交由用户提供设计。
