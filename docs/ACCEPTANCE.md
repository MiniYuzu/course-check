## 本地已验证

上一轮（2026-10-02）本地结果：69/69 项自动化测试通过，60 个源代码、配置与模板文件静态检查通过，`git diff --check` 通过。云端、本地数据链路与界面的独立规格、质量审查均通过。开发分支为 `codex/single-user-reliability`，改动尚未提交。最新结果以上方代码复审记录为准。

- `npm test`：业务单元、云函数入口、前端交互和完整模拟流程。
- `npm run check`：JS 语法、JSON、WXML 标签、事件引用、页面/组件配置、固定 SDK 版本。
- `git diff --check`：差异空白检查。
- 云端身份隔离、无身份拒绝、同日并发去重、创建丢失回执重试不重复。
- 大于单页的课程/历史记录、稳定排序、分页中记录变更重读。
- 初始课时、归档历史、月份边界、中国时区、无效/未来旧日期不计期间统计。
- 存储额度失败不伪装保存成功；确认落盘失败显示失败，队列仍保留。
- 新增本地 ID 在确认和丢失回执后刷新时正确关联云端 ID，不产生两张课程卡。
- 旧版全局缓存不自动迁移/上传，不清理未同步数据。
- 云数据库事务冲突有限重试，权限错误和未知错误不盲目重试；并发、丢失回执及重试行为已通过替身测试。
- 确认弹窗失败后释放按钮并反馈错误；登录延迟返回不会更新已卸载的页面。
- 全流程：离线新增/记课 → 重新启动 → 登录后同步 → 补记 → 撤销 → 归档/恢复 → CSV/JSON 内容导出。

测试的微信 API 和数据库是边界替身，业务代码与云函数入口是真实代码。事务替身强制只用文档 API，并限制单事务操作数；仍不能证明真实云数据库权限、索引、冲突重试或微信运行时已经正确。

## 真实环境待验收

### 配置与身份

- [ ] 用真实 AppID 从仓库根目录导入并成功编译。
- [ ] 云环境 ID、所属小程序与部署环境一致，四函数及三集合齐全。
- [ ] 集合禁止普通客户端直读写，云函数只操作当前微信身份的数据。
- [ ] A 账号建立数据，切 B 后读不到 A 的课程，不上传 A 队列。
- [ ] 测试环境中用错误的预期身份调用课程、记录、统计函数，均拒绝请求且数据库无新增/修改；正确身份正常使用。
- [ ] 真机完全退出后断网重开：提示联网确认身份，而不是创建匿名队列；联网后之前待同步操作仍在。

### 业务与 UI

- [ ] 新建“游泳”，总课时 30、初始已上 10；首页/详情均显示 10/30、剩余 20。
- [ ] 今天点一次：显示 11/30、剩余 19；连续快速点不重复；云端同课同日最多一条新记录。
- [ ] 选过去一天补记：累计 12，所选月 +1；选未来日期不可提交。
- [ ] 撤销补记并确认：累计回 11，日期对应的月统计同步回退。
- [ ] 测试集合里准备旧未来日期及不存在日期的误记，撤销后累计纠正；仍不能新增此类日期。
- [ ] 编辑课时拒绝小数/负数；总课时留空不显示虚假进度；超过总课时明确显示超出。
- [ ] 归档：首页隐藏，统计与历史保留；我的可恢复；归档详情不能新增课或编辑课程。
- [ ] 准备 60+ 条不同日期记录，最后一页不丢；详情/统计/导出计数一致。
- [ ] 切 2 月/3 月和不同年份，日期与所选月一致；近 7 天明确独立于月份。
- [ ] 所有 8 种类型文字可读；小屏、大字体、刘海屏、原生底栏不遮挡按钮。
- [ ] 加载、空内容、网络错误三种状态能区分；错误时不会误报“没有课程”。

### 断网、导出和纠错

- [ ] 已登录后断网新增/修改/记课：明确待同步；刷新不覆盖本机修改。
- [ ] 同步过程中关闭小程序再进入：之前操作可以恢复重试，不永远停在“同步中”。
- [ ] 后端故意报错：显示失败，不提示“同步完成”；队列后续依赖操作不越过失败项。
- [ ] 恢复网络：手动/网络恢复触发同步，确认云端结果后待同步项消失。
- [ ] 同账号另一设备归档课程导致离线记课失败：刷新后明确恢复课程并重试，原记课能够同步，已排队的撤销/归档不丢失；同时覆盖记课请求尚未返回时点击恢复。
- [ ] CSV 在表格软件打开中文正常；带 `= / + / - / @` 的用户文本不被作为公式执行。
- [ ] JSON 完整备份包含原始快照、旧重复记录、待取消记录、队列与 ID 映射。
- [ ] 分享文件由本人选择收件人；取消分享不报成功，旧版缓存导出不上传云端。
- [ ] 微信意见反馈入口真实可用；不展示家庭共享、提醒、成就、假高级模式入口。

## 已知边界与后续工作

- 单个家长；每天每门课只记一节。多人共享或一日多节需要先改变业务规则，不应只改一个数字。
- JSON 备份不等于已经实现自动导入；旧无归属缓存需要人工核对，不能猜账号自动归并。
- 大量旧重复记录的撤销分批执行；中途失败会保留待重试，不宣称整个集合一次原子删除。
- 原生微信视觉与运行时尚未实测；历史 HTML 不作为本轮验收证据。
- 未创建额外管理站点。现阶段使用微信平台与云开发控制台，权限只给可信管理员。
- 未提交 Git、未推 GitHub、未部署或修改线上数据；原有未提交文件和旧资料保留。
