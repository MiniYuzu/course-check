# 课时小记：设计交接与实现验收

更新：2026-10-03。依据当前小程序页面、组件和交互代码整理，不以旧需求或架构文档为准。

## 先看结论

首页以你指定的 `design-variant-B.html` 为视觉基准：蓝紫页头、彩色渐变课程卡片、白色打卡按钮、绿色已打卡状态、虚线添加入口。后续不再自行更换风格。最终确认的细化稿 `course-check-b-refined-preview.html` 已于 2026-10-03 落地到正式小程序：独立卡片分区、亮绿已打卡、虚线时间轴和可选的一句话课后备注。

当前代码有 **5 个页面文件、6 种主要页面形态**：首页、课程详情、添加课程、编辑课程、统计、我的。其中添加与编辑共用一个页面。本轮已完成这些页面及公共组件的统一样式；以下保留为后续修改与验收清单，不再是未完成的设计任务。不需要每门课程单独设计。

建议顺序：**课程详情 → 添加/编辑 → 统计 → 我的 → 公共异常状态与图标**。先把“添加课程 → 首页记课 → 查看/纠正记录”这一条流程画完整。

### 课程详情：布局需要容纳的完整信息

1. 概览：课程名称、类型图标、上课时间；累计已上、总课时和剩余；备注与编辑入口。
2. 记课区：日期选择，默认今天；今天记课或补记按钮。每门课程每天只能记 1 节。
3. 历史区：月份筛选、查看全部月份；每条记录展示日期、同步状态、已有备注和撤销入口；超过 30 条可继续显示。
4. 归档区：归档不删除历史；已归档时改为“恢复到首页”，不显示新增记课和编辑入口。

初始已上课时只进入累计与余额，不会凭空生成带日期的历史。设计稿不要把它画成某一天的上课记录。

本轮新增的课后备注：记课区“记一句（可选）”默认折叠，最多 60 字，随本次记录保存；已有记录只更新备注、不增加课时。历史左侧为日期圆点与浅虚线，点记录正文可编辑备注，取消不保存、留空保存清除；撤销入口独立。课程整体备注仍是表单中的 500 字字段，两者不混用。

### 添加 / 编辑：一套表单，两种状态

| 字段 | 当前输入规则 | 设计提示 |
| --- | --- | --- |
| 课程名称 | 必填，最多 50 字 | 需要长名称显示方案 |
| 课程类型 | 游泳、钢琴、英语、美术、舞蹈、运动、音乐、其他，共 8 类 | 同一个选择组件；可沿用现有 emoji，无须制作课程封面 |
| 总课时 | 可选，非负整数；空或 0 表示不设上限 | 不能用 0 节误导用户以为课程用完 |
| 开始使用前已上课时 | 非负整数 | 需要说明：已逐条补记的课时不要重复填写 |
| 固定上课时间 | 可选，最多 100 字，自由文本 | 只是备忘，不代表已经实现提醒或日历排课 |
| 备注 | 可选，最多 500 字 | 多行输入 |

新增按钮为“添加课程”；编辑按钮为“保存修改”。续课当前通过增加总课时完成，不另做购课或支付页面。

### 统计：图表含义不能混淆

- 累计已上：包含开始使用前已上课时，也保留归档课程的历史。
- 选中月份的课时与天数：只计算有实际日期的记录，不包含初始已上。
- 最近 7 天柱状图：始终是最近 7 天，与上面的月份选择无关。
- 该月各课程数量：当前是列表，可设计成清晰的数量对比；不是已实现的“成就”或“学习效果评分”。
- 该月逐条明细：课程名称、日期、归档标记，每条 1 节；超过 30 条继续显示。

请在稿子里明确“最近 7 天”和“所选月份”的标题，不要让用户误认为两个图表使用同一个日期范围。

### 我的：数据操作页，不是社交个人中心

当前没有头像编辑、昵称编辑、会员、积分或账号切换页面，不需要为这些占位。归档课程和同步详情目前就在“我的”页内；导出与说明使用原生弹窗，不必额外拆页面。

## 3. 公共元素：设计一套，全工程复用

| 编号 | 元素组 | 需要的状态 / 交付 |
| --- | --- | --- |
| C1 | 页面与导航 | 页头/返回/标题的统一规则；底部“课程、统计、我的”3 组图标，选中和未选中各 1 个，共 6 个 |
| C2 | 通用课程卡片 | 未打卡、今日已打卡、操作中/不可用；总课时未设、剩余为 0、已超额；待同步、同步失败；长名称换行 |
| C3 | 按钮与文字操作 | 主按钮、次按钮、撤销/归档等谨慎操作；默认、按下、加载中、不可用 |
| C4 | 表单组件 | 输入框、数字输入、多行备注、课程类型选择、日期/月选择入口、字段说明与错误提示 |
| C5 | 数字与图表 | 数据摘要、课时进度条、7 天柱状图、月份标题；0 值、数量较大时的显示方式 |
| C6 | 列表与标签 | 课程行、历史记录行、归档标签、待同步/失败标签、加载更多 |
| C7 | 状态提示 | 离线、本机已保存待上传、同步中、同步失败及重试、账号尚未确认/读取失败 |
| C8 | 空白与加载状态 | 首次无课程、课程无历史、月份无数据、没有归档、正在加载；可用小型通用图形，不需要每处插画 |

另外提供一页基础规范即可：颜色、字号与字重、页面留白、卡片间距、圆角、阴影。首页以 B 版为参照，其余页由你定稿；我们负责实现与复用。

## 4. 哪些不必重新画

以下目前使用微信原生控件，默认沿用原生外观，只需确认文案与动作：

- 日期与月份选择器。
- 7 类弹窗：补记确认、撤销确认、归档确认、恢复确认、导出隐私提示、旧版缓存备份提示、使用说明。
- 导出格式选择：CSV 课时表 / JSON 完整备份。
- 成功或失败的短提示、文件分享面板、微信意见反馈入口。

这能减少设计量，也不需要为每一个确认动作开发自定义弹层。若确实要改成自定义样式，再单独确认，不默认扩大本轮范围。

## 5. 本期不需要设计的功能

成就/勋章、连续签到奖励、家庭成员/多个孩子、课程提醒、支付/续费购买、社交分享、独立账号登录页、自建数据管理后台均不在当前单人记课界面范围。

已有 JSON 备份导出，但没有“导入备份自动恢复”界面；请不要在稿子里提前增加恢复按钮。

## 6. 最小设计交付包

无需一次完成所有稿子。第一批发“课程详情 + 添加/编辑”即可。

1. 以 375 或 390 逻辑像素宽度制作的手机稿，注明使用的宽度；长页面可分屏展示。
2. 4 类页面的主要画面；编辑复用添加，只标不同之处。首页保留 B 版，再给必要的空/错误状态。
3. 公共组件与状态一页，尤其是按钮禁用、已打卡、待同步、失败、空数据。
4. 如更换图标：提供 3 组底栏图标；课程类型可先沿用 emoji，也可给 8 个可复用类型图标。不需要按“具体哪门课程”逐个设计。
5. 有交互意图的地方加一句说明，例如“点击课程进入详情”“点击撤销先确认”。Figma 链接、HTML 或清晰截图均可；素材有透明背景版本更方便实现。

验收时会检查长课程名、课时较大、无数据、离线与同步失败，确保新设计不是只有样例数据好看。
