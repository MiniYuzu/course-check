# 课时小记 · 单人版

一个家长使用的微信原生小程序：记录每门课上了几节、还剩几节，支持补记、撤销、历史查询和导出。

工程已配置真实 AppID 和云开发环境；2026-10-04 已升级排课相关的 `course`、`checkin`、`stats` 云函数，并在微信开发者工具模拟器连接真实云端完成排课、待确认、缺席扣课、更正出席、撤销与归档验证。217 项自动测试通过；尚未完成手机真机与多设备联调，具体边界见 [验收记录](docs/ACCEPTANCE.md)。根目录的 `design-*.html` 是历史设计示意，**不是当前小程序的运行界面**。

## 已实现

- 课程：8 种类型，新增/编辑，总课时、初始已上课时、每周固定安排、统一备注。
- 首页排序：今日有正式排课的课程按开始时间优先，其余保持原有顺序；同时间不换位，打卡或确认缺席、停课后不跳位，不提供拖拽排序。
- 记课：今天一键记录，同一门课同一天最多一节；补记过去日期，确认后撤销。
- 排课：首页顶部显示所有课程中最近一次上课，以及已结束但尚未确认的计划；只在应用内提示，不发微信通知。
- 出缺席：确认出席、缺席或停课；缺席默认不扣课，也可手动扣 1 节，支持原因、简短备注和结果更正。
- 余额：实际已上与课时消耗分开；剩余、进度及超出课时按消耗计算，未设置总课时则不显示虚假余额。
- 历史：计划与实际记录合并到虚线时间轴，可按全部/待确认/出席/缺席及月份筛选，分批展示；归档后保留历史，可恢复。
- 统计：保留累计、所选月实际出席/上课天数、课程分布、明细和近 7 天趋势，补充缺席、待确认与扣课时信息。
- 数据：持久化离线队列、身份和环境隔离、顺序重试、防重复写入、真实失败状态。
- 导出：CSV 课时表、含原始快照及待同步队列的 JSON 备份；旧版无归属缓存单独备份。
- 界面：浅色卡片、微信原生导航，课程/统计/我的三个页签。反馈使用微信自带入口。

例：总课时 30，开始使用前已上 10，1 月出席 2 次，则已上 12、剩余 18、1 月出席 2。再登记一次缺席并选择扣课，已上仍为 12、余额变为 17；将这次更正为出席后，已上为 13、余额仍为 17，不重复扣课。初始课时不伪造历史日期。续课后增加总课时即可。

## 开始使用排课

1. 在新增或编辑课程的第三分区“上课安排”开启每周固定安排，选择星期与起止时间，明确安排开始日期。
2. 回到首页查看下次上课和待确认提示。只有超过结束时间的未记录计划才成为待确认，系统不会自动判缺席。
3. 在记录列表选择确认结果；缺席默认不扣，按机构约定选择是否扣 1 节，可写一句原因或课后表现。
4. 记错时选择“更正”；撤销会让已有计划重新待确认。统计中的出席与消耗分别变化。

旧手写备忘合并到课程备注中展示和编辑，保存课程时一并存入备注并清空旧字段，不自动变成排课；开始日期以前也不补造计划。已有安排的修改最早明天生效；归档停止未来排课，恢复课程后需要手动重新设置，不会把归档间隔算成缺席。出现同步冲突时，“我的”提供确认后采用云端结果的入口，相关本机修改先移入完整备份，不影响无关操作。

## 一期边界

不是家庭共享、多孩子或教培机构管理系统；不做成就、订阅提醒、支付、课程交易、独立管理后台。没有“开发中”的虚假入口。JSON 目前用于备份与人工核对，**没有自动导入/恢复按钮**。

第一次启动以及完全退出后重新启动，需要联网确认微信身份；未确认前不读取别人的缓存、不创建无归属操作。完成本次登录后断网仍可记课；已保存队列可以跨重启保留，重新联网确认账户后重试。请勿在有待同步记录时清理小程序数据或卸载微信。

## 开发与验证

本地验证使用 Node.js 20 或以上，不依赖微信账号，也不需要安装云 SDK。

```sh
npm test
npm run check
# 或一次执行
npm run verify
```

测试会调用实际前端业务模块和实际云函数入口；只有微信 API/云数据库使用边界替身。静态检查验证 JS、JSON、页面/组件引用、WXML 标签与事件引用，**不是微信编译器**。

云函数 SDK 固定为 `wx-server-sdk@4.0.2`，每个函数都有独立锁文件。部署前可在对应函数目录运行 `npm ci --ignore-scripts`，不要把 `node_modules` 提交到 Git。

排课与出缺席规则以 `miniprogram/utils/attendance.js` 为源文件。修改规则后运行 `npm run sync:attendance`，同步到三个云函数的独立部署包；`npm run check` 会拒绝未同步的副本。先升级相关云函数，再升级客户端，避免新界面连接旧接口。

## 单仓库结构

```text
miniprogram/          微信原生客户端
  config.js          云环境 ID 配置（不存密钥）
  pages/             课程、详情、编辑、出缺席记录、统计、我的
  components/        课程卡片、同步状态等
  utils/             统计规则、存储、同步、数据访问、导出
cloudfunctions/      login / course / checkin / stats，分别部署
tests/               回归测试与完整业务流程测试
scripts/             本地静态检查、共享排课规则打包
docs/SETUP.md        微信工具、账号、云环境与后台配置
docs/ACCEPTANCE.md   验收记录与尚待人工完成的项目
project.config.json  开发者工具从仓库根目录导入的配置
```

旧需求/架构文档和历史设计文件原样保留，本轮没有读取或以它们作为实现依据。原生目录本来就符合微信工具约定，没有为形式上的整洁迁移它们。原有自定义底栏代码未再使用，但它包含此前未提交改动，因此未擅自删除。
