# 课时小记 · 单人版

一个家长使用的微信原生小程序：记录每门课上了几节、还剩几节，支持补记、撤销、历史查询和导出。

本轮是**本地可测试的实现**，尚未配置真实 AppID、云环境，也未通过微信开发者工具编译或真机验收。根目录的 `design-*.html` 是历史设计示意，**不是当前小程序的运行界面**。

## 已实现

- 课程：8 种类型，新增/编辑，总课时、初始已上课时、上课时间备忘、备注。
- 记课：今天一键记录，同一门课同一天最多一节；补记过去日期，确认后撤销。
- 余额：累计、剩余、超出课时；未设置总课时则只显示累计。
- 历史：完整分页读取，按月筛选，分批展示；归档后保留历史，可恢复。
- 统计：累计、所选月课时/有课天数、各课程记录、上课明细、近 7 天趋势。
- 数据：持久化离线队列、身份和环境隔离、顺序重试、防重复写入、真实失败状态。
- 导出：CSV 课时表、含原始快照及待同步队列的 JSON 备份；旧版无归属缓存单独备份。
- 界面：浅色卡片、微信原生导航，课程/统计/我的三个页签。反馈使用微信自带入口。

例：总课时 30，开始使用前已上 10，1 月实际记录 2 次，则累计 12、剩余 18、1 月统计 2。初始课时不伪造历史日期。续课后增加总课时即可。

## 一期边界

不是家庭共享、多孩子或教培机构管理系统；不做成就、订阅提醒、支付、课程交易、独立管理后台。没有“开发中”的虚假入口。JSON 目前用于备份与人工核对，**没有自动导入/恢复按钮**。

第一次启动以及完全退出后重新启动，需要联网确认微信身份；未确认前不读取别人的缓存、不创建无归属操作。完成本次登录后断网仍可记课；已保存队列可以跨重启保留，重新联网确认账户后重试。请勿在有待同步记录时清理小程序数据或卸载微信。

## 开发与验证

本地验证使用 Node.js 20 或以上，不依赖微信账号，也不需要安装云 SDK。

```sh
npm test
npm run check
# 或一次执行
npm run verify
```

测试会调用实际前端业务模块和实际云函数入口；只有微信 API/云数据库使用边界替身。静态检查验证 JS、JSON、页面/组件引用、WXML 标签与事件引用，**不是微信编译器**。

云函数 SDK 固定为 `wx-server-sdk@4.0.2`，每个函数都有独立锁文件。部署前可在对应函数目录运行 `npm ci --ignore-scripts`，不要把 `node_modules` 提交到 Git。

## 单仓库结构

```text
miniprogram/          微信原生客户端
  config.js          云环境 ID 配置（不存密钥）
  pages/             课程、详情、编辑、统计、我的
  components/        课程卡片、同步状态等
  utils/             统计规则、存储、同步、数据访问、导出
cloudfunctions/      login / course / checkin / stats，分别部署
tests/               回归测试与完整业务流程测试
scripts/             本地静态检查
docs/SETUP.md        微信工具、账号、云环境与后台配置
docs/ACCEPTANCE.md   验收记录与尚待人工完成的项目
project.config.json  开发者工具从仓库根目录导入的配置
```

旧需求/架构文档和历史设计文件原样保留，本轮没有读取或以它们作为实现依据。原生目录本来就符合微信工具约定，没有为形式上的整洁迁移它们。原有自定义底栏代码未再使用，但它包含此前未提交改动，因此未擅自删除。

## 下一步

先按 [接入说明](docs/SETUP.md) 注册/登录微信平台、安装开发者工具并取得 AppID 和云环境 ID，再按 [验收清单](docs/ACCEPTANCE.md) 联调。不需要先另做一个网站后台。

推送 GitHub 前应再次检查差异，确认账号配置、导出文件和密钥不会进入仓库。本轮没有自动提交、推送、创建远程仓库或部署线上数据。
